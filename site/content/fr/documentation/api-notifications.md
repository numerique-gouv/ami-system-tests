L'API de notifications permet de déclencher l'envoi de notifications push
vers les appareils enregistrés, utilisée par les tests pour simuler des
événements serveur.

::: rapidoc /openapi/notifications.yaml
:::

> **Note** : remplacer `/openapi/notifications.yaml` par l'URL réelle
> de la spec OpenAPI une fois disponible. Vous pouvez placer un fichier
> `notifications.yaml` dans `site/public/openapi/`.
